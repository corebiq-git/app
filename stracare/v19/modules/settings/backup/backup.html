download Export & Backup Data

Module Export (CSV/Excel)

Download specific tables directly to your device. Staff accounts will only export data related to their assigned branch.

info
Leave the date fields empty to export all available records for the selected module. Date filters apply to the 'Date' or 'Creation Date' depending on the module.

Import Module CSV

Import a CSV or tab-delimited file for the selected module. Blank IDs are assigned the module prefix and next available number (for example, APT-0001). Existing records are never overwritten.

warning
CSV imports are available to administrators only. Check the sample columns before importing. Records already present by ID are skipped. Import appointments from Appointments → More Actions → Import CSV to keep linked patient and transaction records in sync.

Full System Backup (JSON / ZIP / CSV)

Download a complete JSON snapshot, or a ZIP containing one JSON or CSV file per collection and a backup manifest.

warning
Leave both dates empty to include all available records from the beginning of each collection through today. Choose dates to limit the backup by each record's date or creation date. The backup includes all app modules across all branches.

Import Full System Backup (CSV ZIP)

Import a CSV ZIP downloaded from this page. Only documents with new IDs are added; existing IDs are skipped and counted. No existing documents are overwritten or deleted.

warning
Import writes documents to Firestore and may incur usage charges. Use an unmodified backup ZIP from COREBIQ. If an error occurs, the report will show progress; records already added are not rolled back.
